#### Background

As a dad, I found myself paying for multiple apps just to keep our family organized - one for calendars, another for chores, another for meal planning. FamilyHub consolidates everything into one free, self-hosted solution that puts your family's data in your control.

#### Features

- **Shared Calendar**: Family-wide event scheduling with color-coded members
- **Task Management**: Assign chores and track completion
- **Meal Planning**: Weekly meal prep with recipe integration
- **Real-time Sync**: All family members see updates instantly

#### Tech Stack

Built with React 19 and the latest patterns including:
- **TanStack Query** for server state management
- **Zustand** for client state
- **Tailwind CSS v4** for styling
- **Vitest + Playwright** for comprehensive testing
